# jdbc

A self-contained JDBC driver (`java.sql.Driver`/`Connection`/`Statement`/`ResultSet`/
`DatabaseMetaData`) whose "database" is nothing but the filesystem: a catalog is a
directory, a table is a file whose name carries a shared suffix, and rows/columns are
plain text. Two concrete storage flavors exist side by side - fixed-length records
(`*Fix` classes, via `ConnectionFix`/`DriverFix`) and the separator-delimited variant
implemented in the sibling `streamIO.object.parser.jdbc` package - both built on the same
`A*` abstract bases (`AConnection`, `AStatement`, `AResultSet`, `ADBMetaData`) so a new
storage format only has to supply the row-level read/write primitives.

On top of the storage layer sits a small relational-operator toolkit built as
`ResultSet` decorators: `FilterResultSet` is the identity wrapper that subclasses
override selectively, `FilterRsCols`/`FilterRsRows` project columns and filter rows,
and `ResultSetCrossJoin`/`ResultSetLeftJoin` implement joins (the latter indexing the
right-hand side via `IIndexer` for a non-quadratic lookup). `ResultSetArray` and
`ResultSetCount` are in-memory result sets used for caching and for synthetic
single-value results (row counts).
