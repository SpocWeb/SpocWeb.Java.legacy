the program must be able to work in a non-networked mode.
In this mode, the database and user interface run in the same VM and no networking is performed,
no sockets should be created.
The user must be able to select the operating mode,
it is acceptable that the program stay in one mode once it has started up.

You may use either serialized objects over a simple socket connection, or you may use RMI.
Your submission will fail automatically if you do not use one of these approaches.
